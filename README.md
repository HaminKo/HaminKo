# Hi, I'm Ha Min Ko

I'm based in Boston and build personal projects in my spare time, mostly tools, games and mods.

**Latest release:** [Peacefree Revival 1.0](https://github.com/hamsterkoster/PeacefreeRevival), a fan patch that brings back the Flash strategy game Peacefree: Tactical Warfare, fully offline with its premium content unlocked. [Download it here](https://github.com/hamsterkoster/PeacefreeRevival/releases/latest).

**Working on now:** Peacefree Web (a from-scratch browser rewrite of Peacefree that can be modded), SC Map Library (a Windows app for browsing and translating StarCraft: Brood War maps), an analysis of a StarCraft stream's community games, and Slide Out (a co-op sliding-block puzzle), all private while in development. In public: [Session Inbox](https://github.com/HaminKo/session-inbox), a VS Code extension that keeps track of Claude Code sessions waiting on you. [haminko.com](https://haminko.com) has the full list.
